# Images

Drop your real photos here and update the `image` field in `src/lib/data.ts`.

## Expected files

| File                        | Used in                          |
|-----------------------------|----------------------------------|
| `hero.jpg`                  | Homepage hero background         |
| `bakery-interior.jpg`       | About strip (homepage)           |
| `bakery-story.jpg`          | About page story section         |
| `category-cakes.jpg`        | Category card — Cakes            |
| `category-pastries.jpg`     | Category card — Pastries         |
| `category-signature.jpg`    | Category card — Signature Cakes  |
| `category-cupcakes.jpg`     | Category card — Cupcakes         |
| `category-seasonal.jpg`     | Category card — Seasonal         |
| `logo.png`                  | Navbar / Footer logo             |

## Product images

Each product in `data.ts` has an `image` field (e.g. `"/images/vanilla-cake.jpg"`).
Update those paths to match whatever filenames you use.
